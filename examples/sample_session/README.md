# sample_session (synthetic)

A hand-written session bundle used by the tests and the README demo. No real person is described.
It seeds three inconsistencies on purpose so the post-call analysis (D17) has something to find:
years of LLM experience (CV vs. cover letter), sole ownership vs. team effort (cover letter vs.
HR screen), and English level (self-assessed B2 vs. "fluent"). The consent block is empty so the
consent gate (D18) is exercised by the demo.
